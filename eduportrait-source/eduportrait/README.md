## 这是什么

一套**零依赖、可离线、纯确定性计算**的课程数字画像工具：把"教师数字画像 + 学生数字画像"
落到**课程预备 → 课堂教学 → 课程延伸**三个阶段，每个阶段都给出
**采集 → 分析 → 可视化** 的完整链路，并把诊断结果回流到下一课设计。

**全部指标由真实算法算出，没有任何生成式内容充数**：
TF-IDF、LDA、CTT、IRT-2PL、K-Means、Apriori、BKT、改进版 FIAS、社会网络分析……
每个数字都能在"算法与说明"页找到它的计算方法与参数。

## 🚀 快速开始

```bash
# 方式一：直接双击 index.html（file:// 协议同样可用）
# 方式二：任意静态服务
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

- **环境要求**：任意现代浏览器，无构建步骤、无 npm、无网络请求。
- 打开即自动载入示例课（八年级数学《一次函数的图象与性质》，30 名匿名学生 S01–S30），
  点击右上角 **运行分析** 即可看到全流程结果。
- 打包成可分发的单文件：`python3 tools/build_standalone.py`，产物 `eduportrait-standalone.html`
  （已被 `.gitignore` 排除，属构建产物）。
- 换成自己的课：进「① 采集」替换教案、课标条目与各 CSV，再点运行。

## 🏗️ 框架设想

```
                 ┌────────────────────── 「课」= 最小循环单元 ──────────────────────┐
                 │                                                                 │
   教师画像 ─┐   │  ① 课程预备        ② 课堂教学        ③ 课程延伸                  │
            ├───┼─ 采集→分析→可视化  采集→分析→可视化  采集→分析→可视化             │
   学生画像 ─┘   │  锚定教学起点      捕捉过程证据      诊断学习成效                │
                 │        └────────── 诊断结果回流下一课设计 ◀─────────┘            │
                 └─────────────────────────────────────────────────────────────────┘
```

- **适配性** ← 课标契合度 + 教学模式×学习类型适配度
- **过程性** ← FIAS 三维编码矩阵 + 师生互动网络
- **精准性** ← 四类困惑热力图 + 错题关联规则 + 知识追踪
- **链接性** ← 三阶段平行坐标 + 下一课改进清单

## 🧮 算法清单

| 模块 | 文件 | 方法 | 参数 |
| --- | --- | --- | --- |
| 中文分词 | `assets/algos/text.js` | CJK 一元+二元字组，虚词字符过滤 | — |
| 课标契合度 | `text.js` | TF-IDF 余弦相似度 + IDF 加权词条覆盖率 | 覆盖阈值 0.25 |
| 主题模型 | `text.js` | Collapsed Gibbs LDA | α=0.5 β=0.02 iter=160 |
| 知识深度 | `text.js` | 布鲁姆六层认知动词词典 | 归一化 ×100 |
| CTT | `assets/algos/psych.js` | 难度 P、点二列区分度、高低 27% 分组 D | — |
| IRT 2PL | `psych.js` | Bock-Aitkin MML-EM + 数值牛顿 M 步 + EAP；log-normal(0,0.5²) 先验稳定 a | 21 节点 θ∈[-4,4] |
| K-Means | `assets/algos/cluster.js` | z-score + k-means++ + 轮廓系数 | k=3，种子 42 |
| 困惑编码 | `text.js` | 四类关键词词典加权命中 + 题项预设错因兜底 | 教师可人工复核 |
| 关联规则 | `assets/algos/rules.js` | Apriori 逐层生成 | minSup 0.2 / minConf 0.6 |
| 知识追踪 | `psych.js` | BKT 四参数坐标下降极大似然 | — |
| 改进版 FIAS | `assets/algos/interaction.js` | 10×10 迁移矩阵 + 提问/应答/沉默三维扩展 | 3 秒采样 |
| 社会网络分析 | `interaction.js` | 加权度中心度、密度、边缘参与者 | 交互量 < 学生中位数×40% |
| 可视化 | `assets/charts.js` | 手写 SVG，13 类图表，悬停有数据提示 | — |

## 📋 数据格式

所有学生侧数据都是普通 CSV，首列为 `sid`（建议匿名编号）：

```csv
# 题项映射  items.csv
qid,kp,kp_name,lit,main_confusion,text
Q01,K1,变量与常量,抽象能力,概念理解不清,指出气温变化情境中的常量与变量

# 作答矩阵  responses.csv（0/1，可附 t_Qxx 用时列）
sid,Q01,Q02,...,t_Q01,t_Q02,...
S01,1,0,...,38,52,...

# 兴趣量表  interest.csv（各主题 1–5 分 + 行为频次列）
sid,i_数与代数探究,i_图形与几何,...,q_auto,q_ext
S01,4,3,...,2,1

# 自主困惑  confusion.csv
sid,text
S01,我不太清楚变量与常量到底在问什么

# 课堂编码  FIAS：1–10 逗号分隔（3 秒一格）
# 互动边表 sns.csv：from,to,weight
```

## 🔒 数据伦理

- 示例数据为**模拟生成**（`tools/gen_sample.py`，固定随机种子，可复现），不指向任何真实师生。
- 全流程在**浏览器本地内存**完成：无后端、无网络请求、无数据留存。
- 生物识别类高敏感数据不在采集范围内；课堂影像只保留结构化编码。
- 画像结果仅供教学改进参考，**不得用于学生排名、分班或问责**。
