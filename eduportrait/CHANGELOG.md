# 更新日志

本项目版本号遵循语义化版本 `主版本.次版本.修订号`。

## [1.0.0] — 2026-10-31

首个可用版本，覆盖论文《数字画像赋能"教-学-评"一体化的框架设计研究》的三阶段框架，
其中**课程预备阶段**为完整实现，课堂教学与课程延伸为配套面板。

### 新增

**框架设想**
- 以「课」为最小循环单元的三阶段闭环视图
- 教师 / 学生双画像指标体系表、四重困境对应关系表

**采集（课程预备阶段）**
- 教师侧：教案文本、课标条目、可增删的教学环节用时表、教学模式自述
- 学生侧：题项映射、预习案作答、课后练习作答、兴趣量表、自主困惑（粘贴或上传 CSV）
- 11 项采集完整性核对清单

**分析**
- 教师侧：TF-IDF 余弦相似度矩阵、IDF 加权词条覆盖率 → 课标契合度；
  知识种类 / 深度 / 广度 / 分布平衡性四维得分；布鲁姆认知层级；素养覆盖；LDA 主题
- 学生侧：CTT（难度 P、点二列区分度、高低 27% 分组 D、离散度）；
  IRT-2PL（MML-EM + log-normal 先验 + EAP）；掌握概率矩阵；可疑题项判定；
  K-Means 兴趣聚类；四类困惑词典编码；教学模式 × 学习类型适配度
- 7 个阈值参数（达标线、覆盖率、区分度下限、LDA K、聚类 k、minSup、minConf）可调并实时重算

**可视化**
- 13 类手写 SVG 图表：克利夫兰点图、热力图、堆叠条、环形图、水平条、棒棒糖图、
  斜率图、平行坐标、FIAS 10×10 矩阵、时序条带、SNA 拓扑、瀑布图、散点+ICC
- 每张图配"怎么读 / 怎么做"提示；悬停显示数据

**课中 · 课后**
- 改进版 FIAS（10×10 迁移矩阵 + 提问类型/应答层次/沉默性质三维扩展）
- 社会网络分析（中心度、密度、边缘参与者）
- 掌握率斜率图、BKT 知识追踪与留存率、Apriori 错题关联规则、损失瀑布图

**三阶段综合**
- 平行坐标演变轨迹、学生 × 知识掌握矩阵、持续性困难名单、下一课改进清单

**工程**
- 零依赖、零构建、可离线；`tools/gen_sample.py` 生成可复现的模拟数据；
  `tools/build_standalone.py` 打包单文件 HTML
- 画像结果可导出 JSON

### 已知限制

- IRT-2PL 在 n<30 时仍可能不稳定，已用 log-normal 先验缓解，建议配合 CTT 交叉判读
- 困惑编码基于词典，召回有限，界面保留教师人工复核入口
- 课堂教学数据需外部系统（语音识别 / 行为分析）产出编码后导入，本工具不做原始信号识别
